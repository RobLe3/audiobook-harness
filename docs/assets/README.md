# Review Center walkthrough

`review-center-workflow.gif` is the GitHub-compatible animation used by the
main README. GitHub deliberately renders repository `.html` files as source;
it does not run their JavaScript.

To open the interactive version locally, from this directory run:

```bash
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000/review-center-workflow.html>. The page is
self-contained and makes no network requests.
