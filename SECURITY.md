# Security and privacy

No telemetry, cloud API, automatic update, or model download occurs during
analysis, generation, verification, or release. Setup downloads only after
explicit user confirmation and verifies SHA-256 hashes from `models.lock.json`.

Do not commit manuscripts, generated audio, model files, API keys, private voice
assets, or personal data. Report vulnerabilities through the repository's
private GitHub Security Advisory channel; do not open a public issue. Supported
versions are the latest tagged release and `main`. We target acknowledgement
within seven days and an initial assessment within fourteen days, then agree a
coordinated disclosure timeline with the reporter. Redact copyrighted inputs,
manuscript text, audio, credentials, and voice data from reports; provide only
the minimum reproducible metadata and hashes needed to investigate.
